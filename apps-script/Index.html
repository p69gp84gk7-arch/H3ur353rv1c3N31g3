Chargement…

1. Choisissez un type  ·  2. Glissez la souris sur la ligne d'un salarié  ·  Cliquez sur un créneau pour le modifier (pause repas, horaires…), tirez ses bords pour l'allonger, faites-le glisser pour le déplacer (même vers un autre salarié). Copier : Ctrl (ou Alt) + glisser un créneau, ou bouton « 📋 Copier » dans sa bulle. Les heures entre 21h et 6h passent en nuit automatiquement.

Choisissez un type, puis glissez le doigt sur la barre d'un salarié, ou touchez « + Ajouter ». Touchez un créneau pour le modifier ou le copier (📋 dans la bulle).

Compteur par salarié (saison)

Chaque semaine est comparée à 35h. Solde = dépassements − heures manquantes − heures récupérées. Les semaines pas encore planifiées ne sont pas comptées.

Écart à 35h, semaine par semaine

Rouge = heures manquantes · Orange = dépassement · Vert = 35h pile · Hachuré = pas encore planifié. Cliquez sur une case pour ouvrir la semaine.

Salariés

Une ligne par salarié. Décocher « Actif » le retire du planning sans effacer son historique.

Règles RH

Valeurs utilisées pour les calculs et les alertes (Code du travail, art. L3121-1 et suivants). Modifiez-les ici si votre accord d'entreprise diffère.

Types de créneaux

« Horaires » = on dessine des heures précises. « Journée entière » = la case couvre la journée et compte un forfait d'heures. « Puise dans le solde » = ces heures sont retirées du solde d'heures supplémentaires (récupération).

Stations

Utilisées pour ranger les salariés et filtrer le planning.

Saison

Le récap et les cumuls portent sur cette période. Dates au format jj/mm/aaaa.

Jours fériés

Par défaut, un jour férié est travaillé (saison d'hiver) : les heures faites ce jour-là sont comptées à part pour la paie. Cochez « Chômé » pour qu'il soit posé automatiquement pour tout le service (forfait 7h).

Base de données Google Sheet

Toutes les données sont enregistrées dans le Google Sheet « Heures Service Neige – Base de données », un onglet par sujet. Les onglets manquants sont créés automatiquement.
